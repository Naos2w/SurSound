# SurSound

Cross-platform general-purpose wireless audio sharing and surround sound for iOS and Android.

## Product direction

SurSound is a wireless audio system, not a music player. It captures permitted audio from other apps and distributes it over a local network to participating devices. Users can select party, stereo and surround modes. No account or cloud service is required for core local functionality.

## Status

Phase 0 — technical feasibility. No working app, supported-source guarantee or released version yet.
